# Hummm... I Have a Question for You

A bilingual, playful dating reservation web app built with Next.js.

## Edit locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

The main experience and translations are in `app/page.tsx`. Visual styling is in `app/globals.css`, and the bear illustration is in `public/love-bear.png`.

## Deploy with Vercel

1. Upload this folder to a new GitHub repository.
2. In Vercel, choose **Add New → Project**.
3. Import the GitHub repository.
4. Keep the detected framework as **Next.js** and click **Deploy**.

No environment variables or database are required.
